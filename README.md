 🚀 Jeevan OS

Jeevan OS is a personal life operating system for Android that combines **Career Intelligence, Health Intelligence, Finance Management, and AI-powered Productivity** into a single application.

Rather than using multiple apps for learning, health tracking, finance management, and daily productivity, Jeevan OS serves as a centralized platform designed to help users improve their professional growth, wellness, and financial awareness.
